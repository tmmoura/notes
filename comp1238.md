# Notes for midterms

## Week 1 -  History 
- One writing system can be used by many languages.
- The Sumerians created the oldest known writing system, Cuneiform.
- A monospaced \(fixed-width\) font is a font whose characters each occupy the same amount of horizontal space.

## Week 2 - Bits and Bytes
- ASCII Table: Maps numbers to characters \(e.g., 65 for 'A'\).
- RAM is fast and volatile memory \(loses data when power is off\), Storage \(HDDs and SSDs\) are long-term data storage and retains data without power.
- Bit is short for binary digit, represents one of two states \(0 or 1\), Bytes are group of 8 bits and Binary Numbers are numbers represented using base 2.

## Week 3 - Text Structure
- Markup Languages: Markdown \(simple syntax for formatting\), HTML \(more verbose than Markdown\).
- To escape in Markdown, use \ before the special symbol \(Example: \\# to display \#\).
- UTF-8 is identical to ASCII for all the basic characters but uses multiple bytes for codepoints above 127. UTF-8 is by far the most popular encoding on the internet.

## Week 4 - Keyboard & Editors
- QWERTY is the most common layout for English keyboards.
- Text Editors: Vim and Visual Studio Code \(VS Code\) are popular editors; IDEs \(Integrated Development Environments\) like WebStorm, Pycharm; Microsoft Word is a *Word Processor* and Notepad is a *Text Editor*.
- Multiple Cursors in VS Code: Use Ctrl + D to select multiple occurrences.

## Week 5 - CLI \(Command Line Interfaces\)
- Advantages for CLI Usage: Faster for certain tasks compared to graphical interfaces; Efficient for remote work with low bandwidth requirements; Easier automation through scripting.
- SSH \(Secure Shell\) - Connect to remote computers securely / Allows command line access to remote systems
